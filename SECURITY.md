# Security reports

This experimental alpha has no supported production release or response-time commitment. Do not post credentials, exploit details, or customer data in public issues. Use the repository's private vulnerability reporting form when enabled: https://github.com/IntelIP/autonomous-development/security/advisories/new

Provide the affected revision, runtime, impact, and a minimal redacted reproduction. Do not run against other users' systems. Worker outbound allowlisting and unattended reboot recovery remain unfinished.
