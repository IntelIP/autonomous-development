# Runtime evidence and limits

Pi completed a real product ticket through independent checks, exact-candidate lead review, and draft PR publication. The run required operator corrections. It does not establish unattended reliability.

Codex and OpenCode performed real implementation and repair work and passed independent checks in supervised product trials. The lead rejected their final candidates. Claude Code performed real work using an existing local Ollama model; its final candidate was also rejected. That trial does not establish Anthropic model quality.

A generic Codex 0.155.1 worker image was built from Node 22.22.0 in a fresh Linux container. Native CLI execution passed. A fresh Linux controller container imported the source bundle, authenticated to GitHub, and generated a synthetic ticket with a deliberately failing baseline. Its delivery stopped before planning because the required external lead sandbox was missing.

These are distinct results. Fresh complete host installation, accepted fresh-container delivery, mixed-runtime teams, and reliable overnight operation remain unproven. Fixture tests do not establish provider access. No agent quality ranking is claimed.
